# 📝 Task Organizer

Task Organizer is a simple and efficient web application to manage your daily tasks.  
It allows you to **add, edit, delete, and organize tasks** with categories, due dates, and priorities.

---

## 🚀 Features
- ➕ Add, edit, and delete tasks  
- ✅ Mark tasks as completed  
- 📅 Set due dates and priorities  
- 🔍 Search and filter tasks  
- 🗂️ Organize tasks by categories  
- 📊 Progress bar to track task completion  

---

## 🛠️ Technologies Used
- **HTML5**  
- **CSS3 / Bootstrap / TailwindCSS**  
- **JavaScript (ES6)**  
- **Font Awesome**
